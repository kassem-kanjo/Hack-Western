# Copy rules

Plain words for a bridge officer, not a data team. A missing value names what is missing; it never shows a dash.

| We used to say | The screen says |
| --- | --- |
| "listed", "watchlist" | "sanctioned", "shadow-fleet tanker", or "sanctioned or shadow-fleet ship" |
| "shadow fleet" on first mention | "shadow fleet (ships that move sanctioned oil)" |
| "went dark" | "switched off its transponder" |
| "AIS" in a headline | "transponder" or "not broadcasting its position" (AIS only in small print) |
| "IMO" | "permanent ID number (IMO)" |
| "spoof" | "faked position" |
| "radar unmatched" | "seen by satellite radar, not broadcasting" |
| "reach" | "where it could have gone" |
| "msgs/min" | "position reports a minute" |
| "—", "--", or a blank cell | "No flag broadcast", "Not on a sanctions list", "No alarms yet", "None yet" |

## In a sentence

- The tanker switched off its transponder south of Hormuz; satellite radar saw it where it could have gone, but no position reports arrived.
- This sanctioned or shadow-fleet ship is not on a sanctions list under that name, and its permanent ID number (IMO) is 9123456.
- No alarms yet. The lookout has seen no ship that is not broadcasting its position.
