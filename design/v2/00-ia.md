# Dark Fleet: information architecture (v2)

**One bar, three places, one overlay.** Global / Baltic / Edge unit, plus Present (key P) and a mode badge (LIVE / REPLAY / SNAPSHOT). Depth (event, case) is a breadcrumb row under the bar, never more tabs. Esc goes back one level; 1/2/3 switch place.

```
Global (snapshot) ── Overview ──► Case file ──► (meeting = a case kind, no Rendezvous tab)
                          └──► "How sure are we?" (validation: AUC 0.87, radar vs chance 1.07x)
Baltic (live/replay) ─ Live map + ranked list ──► Event detail (silence, jump, clone, meeting)
Edge unit ─────────── single screen: camera, AI on/off
Present (overlay on any screen) ─ steps = data {route, focus, caption}
```

| Screen | The one question | Eye path |
|---|---|---|
| Global overview | How much is suspicious, how much is cleared? | 19 (hero) -> the 19 on the map -> list row |
| Case file | Why was this ship flagged, what clears or condemns it? | ship + verdict -> lens and timeline -> sources, caveats |
| Baltic live | What is happening right now? | "8 events" + coverage -> markers -> ranked list |
| Event detail | What happened, what proves it? | big number -> one sentence -> proof picture -> map -> numbers |
| Edge unit | Does the camera see what AIS does not? | camera frame -> detected vs broadcast -> AI toggle |
| Presentation | What is the point of this step? | caption -> highlighted part of the live view |

Rules for every screen: one hero number, at most ~7 list rows, colour only with meaning (amber went quiet, white impossible, pink met, violet could-have-been, blue radar, red only for a watchlist hit or an error), sources and caveats one click down.

**V1 (Sat 12:00):** nav bar, Baltic live (dots, markers, list, coverage, badge), event detail, calmer overview (this folder), time strip with ticks and a Replay button.
**V2 (Sat 20:00):** Presentation mode, replay scrubbing, "Replay this event" physics explainers (lens growing, speed bars, twin squares flipping, tracks converging), live edge panel.
**V3:** landing page, 3D globe, phone view, per-ship page.
**Removed:** Rendezvous, Live and Case file as top-level tabs; region/period controls in the bar; KPI strip and rail bar chart on the overview.
