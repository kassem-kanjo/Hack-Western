01 Overview

01-overview.html · 1440 x 900 · placeholder data
  1. Grid. 1000 px map + 440 px case rail. The map is the answer; the rail is the worklist. Both stay on every screen so the eye never relearns the layout.
  2. KPI strip above the map, not beside it. Five numbers at 44 px mono, ordered as the story: tracked, dark events, hours dark, candidates, meetings. Colour of the number = colour of its map symbol (amber, blue, pink).
  3. Ranked case list. Sorted by risk score. Each row: rank, id, hours dark (largest number, amber), risk chip with a text label and a bar (never colour alone), SAR candidates in prism, meeting chip. Click opens the case file (screen 02).
  4. Symbols are redundant on purpose. Gap = dashed line, SAR = diamond, meeting = double ring. Hue and shape both carry meaning, so a colour-blind judge still reads the map. Legend always visible.
  5. Attribution "Powered by Global Fishing Watch" bottom-left on every map. Mode badge (live / snapshot) in the top bar, never hidden.
  6. Wireframe shapes stand in for coastline; values are placeholders, not data.
