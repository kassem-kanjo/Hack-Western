## CSS changes per file (in order)

**tokens.css** — replace with `design/tokens.css`. It keeps every old `--c-*`, `--fs-*`, `--r-*` name as an
alias, so nothing breaks; migrate call sites to the new names file by file, then delete the alias block.
Imports the @fontsource weights (Plex Sans 300/400/500/600, JetBrains Mono 400/500); remove any other font
imports in `main.ts`.

**watch.css**
- Delete the three `font-family: system-ui ...` lines (`.main.watch-main`, `.topbar.is-watch`) and all
  `.topbar.is-watch *` overrides; the shared top bar now matches kit `.topbar`.
- `.main.watch-main`: columns `320px minmax(0,1fr)`; focus `320px minmax(0,1fr) 360px`; rows `minmax(0,1fr) 56px` for the timeline under the map only.
- `.watch-filter-kinds`: one row, `display:grid; grid-template-columns:repeat(4,auto); gap:4px; justify-content:space-between`. `.watch-kind` = kit `.chip` (h 22, padding 0 5px, 11.5 px). Replace `.watch-square` with the 12 px SVG kind glyphs (`build/lib.py: kind_glyph`).
- `.watch-row` = kit `.qrow` (h 52, grid 20/1fr/auto, rows 18/16, selected = `surface-sel` + 2 px accent bar). Add group headers "Happening now" / "Earlier"; drop severity sort.
- `.watch-select` + `.watch-window` → one `.seg` (All / Baltic / Hormuz with alert counts). Drop the 6 h / 12 h toggle from the list header.
- `.watch-layers` (checkbox box) → delete; layer toggles become legend rows (kit `.legend`).
- `.watch-map-btn` → kit `.mapctl button` (28 px, joined, r 4 outer).
- `.watch-live`, `.watch-attrib` → move into the status bar; the map keeps only crumb, zoom, legend, inset, scale, cursor.
- `.watch-details*` → focus panel: head block (tag + 20/600 name + id line), 3-up figure row, "why" sentence, Could-have-met table (`table-layout:fixed`, cols auto/72/64/96), field table, sticky action row (primary "Open case file").
- `.watch-nearby-table tr.is-sanctioned td` → `.tag.sanc` "Sanctions list" in its own column; no red text on whole rows.
- `.watch-area-label.*`: 11/500 with halo; listening areas no outline, watched = dashed `map-area`.
- New `.watch-timeline` (kit `.timeline`) under the map.

**watchMap.ts paint (not CSS but same pass)** — vessel layer (line ~1805): add `map.addImage('chev', sdfCanvas, {sdf:true})`
and a `symbol` layer filtered `sog >= 0.5 && cog != null` with `icon-rotate: ["get","cog"]`,
`icon-rotation-alignment: "map"`, `icon-color: --geo-vessel`, size 0.5→0.9 by zoom; keep the circle layer
for the rest at r 1→2.4. Prism fill → `--geo-reach-fill` + 1 px `--geo-reach` line; add a hatch pattern image.
Backend: add `"cog": last.cog` to the ships payload in `scripts/build_watch.py` (ships builder).

**patrol.css**
- `.main.patrol-main`: grid `672px 368px` over a full-width reliability band; right rail 400.
- `.patrol-frame`: 640 x 480 at 1:1, 1 px `line-2`; HUD corners (`.hud` in `patrol.html`), detection = ice corner brackets + `accent` label tag.
- `.patrol-states` + `.patrol-metrics` → vertical chain (`.node`: 9 px state dot on a 1 px spine, title 14/600, sub 12 `text-3`, figure 24/300 + caption, state word in state colour).
- New verdict block at the top of the rail: 2 px state-colour top rule, 12 px square + 20/600 sentence.
- `.patrol-metric` tiles → 4-up `.tiles` with figures; recovery over target turns `st-degraded`. Budget bar 6 px, marker at the deadline.
- `.patrol-kill` → `.btn.danger`, `.patrol-stress` → `.btn`, both full width, left-aligned.
- `.patrol-offline`: keep, but render inside the same layout (frame shows "Unit offline · last seen ..."), not a centred page.

**screens.css**
- `.chip-pill.is-gap` → `.tag.dark`. `.stage .map-chips` → kit `.crumb` floating panel.
- `.banner`: margin 12/16, `surface-2`, 2 px left rule in state colour (no tinted box).
- New: `.block` (padding 14/16, `line-1` bottom, 16/600 finding title) and `.two` (2-col tests) for Evidence.

**console.css**
- `.topbar`, `.tab`, `.mode-badge` → kit `.topbar`, `.nav a`, `.mode` (h 40 bar, 1 px underline tab, dot badge).
- `.kpi-strip` / `.kpi` → figure rows (`.figs`, `.figs3`): 300 weight, no boxes, `line-1` separators.
- `.legend`, `.swatch.*` → kit `.legend` with real glyph SVGs; delete `.swatch.is-lens/.is-likely` purple fills.
- `.case-row` → Evidence `.crow` (score figure + 3 px band bar, name/meta, dark hours + radar count right).
- `.chip.is-high/.is-med/...` → `.tag` variants. Any `border-radius: 8px` / pill → `--r-1`.
- `.attribution` → status bar right side + map-corner text only where radar is drawn.

**nav.css**
- `.present-btn`: h 28, `--r-1`, kit `.btn` default; key hint uses `.kbd` (mono 10).
- Remove `min-width: 18px` from `.kbd`; padding 0 4px, line-height 14 px.

queue rows, chips, seg. 4. Map: neutral vessels + chevrons (+ backend `cog`), reach styling, labels, legend.
5. Focus panel. 6. Timeline. 7. Hormuz tiles + chart + meetings dedupe. 8. Evidence. 9. Patrol.
